# Library Management System in C++

## About Project
This project is a simple Library Management System developed using C++. It helps manage different library items such as books, DVDs, and magazines.

## Features
- Display all library items
- Check out library items
- Return library items
- Search items by title
- Display item details and availability status
- Handle invalid inputs using exception handling

## Library Items
- **Book:** Title, author, ISBN, and pages
- **DVD:** Title, director, and duration
- **Magazine:** Title, publisher, and issue number

## Concepts Used
- Classes and Objects
- Inheritance
- Abstraction
- Polymorphism
- Constructors
- Virtual Functions
- Exception Handling
- Dynamic Memory Allocation

## Technologies Used
- C++
- VS Code

## Purpose
The purpose of this project is to practice Object-Oriented Programming (OOP) concepts by developing a basic Library Management System.
